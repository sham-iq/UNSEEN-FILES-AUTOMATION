# Unseen Files — automated daily video generation and publishing

This repository creates a vertical 60-second Unseen Files video in GitHub Actions and attempts to publish it to the Facebook Page automatically at **8:00 PM Sri Lanka time**.

## One-time setup

In **Settings → Secrets and variables → Actions**, add this repository secret:

- `FB_PAGE_ACCESS_TOKEN` — a valid Facebook Page access token with permission to publish videos. Keep it secret; never commit it to the repository.

The Page ID defaults in the workflow to `1360132067172555`; the `FB_PAGE_ID` repository variable is optional.

## What happens automatically

1. GitHub Actions starts daily at 14:30 UTC (8:00 PM Sri Lanka time).
2. The Python script selects a daily topic from the built-in Unseen Files psychology/mystery story library and creates six vertical cinematic scene cards plus a caption.
3. Edge TTS generates English narration; FFmpeg combines the visuals and narration into a vertical MP4.
4. The workflow uploads the MP4 directly to the configured Facebook Page.
5. A copy of the generated files is retained as a workflow artifact for three days.

## Important limitations

- This creates automated, template-based cinematic visuals with narration. It does **not** generate photorealistic AI footage and does **not** use Google Flow credits. Google Flow has no supported public API currently wired into this workflow.
- The built-in topic library repeats on a rotation; the script is not generated by a live AI model.
- The first run must be checked to confirm that the Facebook token is valid and has video-publishing permissions. If Facebook rejects it, open the Actions run logs to see the API error.
- GitHub scheduled jobs are best-effort and can start late.
- GitHub Actions, Edge TTS, and Facebook are external services, so a completely unattended run cannot be guaranteed if any service, quota, or credential fails.

## Test

Open **Actions → Unseen Files Daily Publisher → Run workflow** for an initial test. After credentials and publishing are verified, the scheduled run is automatic; you do not need to keep your Mac on or supply a video URL each day.
